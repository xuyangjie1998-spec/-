🚀 快速入门

                
San7ModMaker 是三国群英传7的MOD制作工具，可以编辑武将、兵种、物品、技能等游戏数据，创建完全自定义的三国群英传7体验。

                
    
                    
  1. 设置游戏目录：在"游戏设置"页面选择游戏安装位置
    2. 
                    
  2. 解压资源：用RPGViewer解压Sango7.pck（详见设置页教程）
    3. 
                    
  3. 开始编辑：点击左侧导航进入对应编辑器
    4. 
                    
  4. 保存修改：编辑完成后点击"保存修改"按钮
    5. 
                

            


            

                
📚 术语词典

                

                    
TermText — 游戏文本数据库，管理所有游戏中显示的文字。ID 13000+ 为兵种名，14000+ 为物品名，25000+ 为武将名。修改名称实际上是在修改 TermText。

                    
OBD — 千人战模型定义文件。BFSoldier.obd 定义兵种模型，BFGen.obd 定义武将模型，BFWeapon.obd 定义武器模型。控制战场上的角色外观。

                    
SHP — 游戏专用图片格式，类似精灵图。头像、物品图标、界面元素都是 .shp 文件。软件支持预览和像素级编辑。

                    
PCK — 游戏资源打包格式。Sango7.pck 包含所有 Setting 配置文件，Shape00~06.pck 包含图像资源。需要用 RPGViewer 解压。

                    
DefSkill / 个人特性 — 武将的专属被动技能，如"骁勇"、"迅雷"等。在 GenSkill.ini 中定义，编号对应 General01.ini 中的武将编号。

                    
General02 — 武将出生地配置。控制武将初始所属城池、登场剧本和登场年份。

                    
BFMagic / SFMagic — BFMagic 是必杀技（BattleField Magic），SFMagic 是普通技能（Standard Field Magic）。在兵种编辑器中用于配置兵种可用的技能。

                    
GenLevel / 等级经验 — 武将升级所需经验值表。控制每级需要多少经验。

                    
Script.so — 游戏核心脚本库文件。包含战斗逻辑、AI行为、事件触发等底层代码。高级功能需要逆向工程分析。

                    
INI 文件 — 游戏配置文件格式。大部分游戏数据都存在 .ini 文件中，如 General01.ini（武将数据）、Thing.ini（物品数据）等。

                    
Big5 编码 — 游戏使用繁体中文 Big5 编码。如果看到乱码，可能是编码设置不正确。软件会自动检测编码。

                    
城池 / City — 游戏地图上的城市。编辑城池属性可以修改城池的防御、人口、可购买物品、太守等。

                    
阵型 / Formation — 战斗时的阵型排列。控制士兵和武将在战场上的站位。

                    
势力 / Nation — 游戏中可选的势力。每个势力有独特的颜色、君主和初始城池。

                    
MPC — 地图地形数据格式。控制战场地图的地形类型。

                

            


            

                
💡 基本操作

                
    
                    
  • 加载数据：点击左侧导航进入编辑器，数据会自动加载
    • 
                    
  • 编辑字段：在右侧详情面板修改数值或文本
    • 
                    
  • 保存修改：Ctrl+S 或点击"保存修改"按钮
    • 
                    
  • 新增条目：点击"新增"按钮创建新记录
    • 
                    
  • 删除条目：选中后点击"删除"按钮
    • 
                    
  • 搜索过滤：在列表上方搜索框中输入关键词
    • 
                    
  • 撤销操作：Ctrl+Z 撤销上一步
    • 
                    
  • 全局搜索：左侧"全局搜索"可跨所有数据表搜索
    • 
                

            


            

                
🔗 数据联动

                
    
                    
  • 修改武将编号 → 自动同步 DefSkill / General02 / TermText
    • 
                    
  • 新增兵种 → 自动创建兵符物品
    • 
                    
  • 修改城池 → 自动同步 TermText 名称
    • 
                    
  • 修改必杀技 → 自动同步 TermText 名称
    •

    3. 
                    
  3. 在对应编辑器中微调属性
    4. 
                    
  4. 使用「备份还原」保存当前状态
    5. 
                    
  5. 使用「数据校验」检查配置正确性
    6. 
                    
  6. 使用「MOD管理」打包发布
